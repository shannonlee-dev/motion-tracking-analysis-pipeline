# 동작 추적·대상 매칭 분석

**현재 MOG2 → bbox → 중심점 추적 구조로는 신체 분리·정지·가까운 사람 구분을 함께 안정적으로 해결하지 못했다.**
시간적 조각 재구성을 앱에 구현했지만, 미사용 영상에서 누락·합침도 늘어 기본 적용을 보류했다.
`--compose-fragments 1`로 후보를 실행할 수 있으며 기본값은 `0`이다.
SIFT는 등록 대상 찾기용으로 유지한다. 실행 명령은 [실행·평가 가이드](recipes/tracker.md), 구조는 [README](../README.md)에 있다.

## 전경 분리 원인과 구현

| 단계 | 확인한 문제 |
| --- | --- |
| MOG2 원시 라벨 | 신체 일부가 배경(0)·그림자(127)로 분류된다. 19번 f216은 사람이 서 있어도 전경이 거의 없다. |
| 이진화 | 라벨 >200만 남겨 그림자로 분류된 신체도 제거한다. 10번 f87의 다리 주변에서 확인했다. |
| OPEN → CLOSE | OPEN이 가는 연결을 끊고 CLOSE가 이를 복구하지 못한다. 10번 f87은 전체 전경 842픽셀 중 288픽셀이 OPEN에서 제거됐다. 사람 픽셀만의 손실률은 아니다. |
| 객체 구성 | 기존에는 면적 필터를 통과한 윤곽 하나를 객체 하나로 취급했다. 18번 f164의 머리·몸통이 따로 남는다. |
| 추적 | 기존 ID에는 조각 하나만 대응하고, 나머지에 새 ID를 발급한다. 중심 위치만으로 같은 사람인지 판별하지 못한다. |

단계 화면: [10번](evidence/fragmentation/baseline/10_stages.jpg), [18번](evidence/fragmentation/baseline/18_stages.jpg), [19번](evidence/fragmentation/candidate/19_stages.jpg).
전역 연결 성분 감소에는 잡음 제거도 포함되므로 신체 분리 개선으로 해석하지 않았다.

구현은 두 가지다. OPEN/CLOSE 커널을 독립 설정으로 분리하고, `Tracker.compose()`를 ID 대응 전에 추가했다.
최근 2프레임 이내 객체 bbox를 폭 15%·높이 10%만큼 확장한 영역에 조각의 80% 이상이 들어가고,
그 소유 후보가 정확히 하나일 때만 구성한다. 합친 크기는 이전 폭의 0.65–1.3배·높이의 0.65–1.2배 이내이며,
이전 면적의 절반 이상인 큰 조각 두 개는 합치지 않는다. 모든 영상에 같은 비율을 적용한다.

구성 bbox는 **실제 관측 조각의 외접 범위**다. 모호한 조각은 그대로 남기고, 전경 마스크는 바꾸지 않는다.
이전 bbox를 복사해 미검출을 성공으로 표시하지 않는다. `FrameResult`는 원시·이진·OPEN·최종 마스크,
조각 bbox·구성 bbox·활성 ID를 평가기에 제공한다.
재구성 조건은 객체 크기 비율이지만, 면적 임계값·거리 게이트까지 해상도 불변으로 바꾼 것은 아니다.
첫 관측부터 분리된 사람, 장기 정지·가림, 이미 잘못 합쳐진 기준 bbox는 해결하지 못한다.

## 검증 기준

2026-09-21 측정. 개발은 **02·10·18**, 검증은 나머지 **14개 영상**으로 먼저 고정했다.
인접 프레임을 나눈 holdout이 아니며, 검증 후 알고리즘 임계값을 바꾸지 않았다.
다만 일부 CAVIAR 영상은 카메라·도메인을 공유하므로 완전한 카메라 외부 일반화 검증은 아니다.

17개 영상 7,983프레임 중 warmup 25프레임 이후 GT가 있는 4,985프레임을 평가했다.
사람-프레임은 개발 2,090·검증 8,348이며, 160×120·352×288·384×288 영상의 이동·정지·재출발·교차·가림·조명 변화·작은 사람을 포함한다.
14번의 120개 GT 프레임은 기존 수동 bbox 근사다. GT 없는 12·13은 합계에서 제외했다.

| 지표 | 정의 |
| --- | --- |
| 조각 연결 | GT 면적의 5% 이상과 교차하고 예측 면적의 50% 이상이 GT 내부 |
| 중복 조각·분리율 | 사람별 `max(연결 조각 수−1, 0)` 합계 / 조각이 둘 이상인 사람-프레임 비율 |
| 충분한 포착 | GT의 70% 이상을 덮고 예측 면적의 50% 이상이 GT 내부인 일대일 대응 |
| 평균 포착 정도 | 사람별 최고 단일 bbox GT 포착률 평균. 예측 순도 50% 미만은 0 |
| 누락 | 연결된 조각이 없는 사람-프레임 |
| 합침 후보 | 한 예측이 서로 다른 GT 둘 이상을 각각 50% 이상 덮음 |
| GT 미대응 박스 | 어떤 GT와도 조각 연결이 없는 예측. 오검출 대용 지표 |
| ID 변경 | 충분한 포착 대응 ID가 마지막 유효 대응과 달라진 횟수. 누락 간격을 넘어 기억 |

이는 **bbox 지표이며 신체 픽셀 IoU·MOTChallenge IDSW가 아니다.** 작은 다리만 잡아도 누락은 피할 수 있어 충분한 포착과 함께 본다.
GT가 겹치면 조각·합침 대응이 모호해 화면 검토를 병행한다. 오래된 내부 트랙은 제외하고 `missing==0`만 평가했다.
전체 집계는 가림을 제외하지 않는다. 보조 `events.csv`만 기존 사건 제외 구간을 따르며, 사건끼리 겹치므로 전체 합계에 더하지 않는다.

### 비용과 회귀 검증

새 의존성은 없고 조각 N·최근 트랙 T에 대해 O(NT) 비교가 추가된다.
OpenCV 1스레드, 관찰자·인코더·SIFT 없이 실제 앱을 5회씩 AB/BA 실행한 FPS 중앙값은 다음과 같다.
디코딩·오버레이를 포함하며 원본 재생 FPS와 다르다.

| 영상 | 기존 FPS | 후보 FPS | 프레임당 시간 변화 |
| --- | ---: | ---: | ---: |
| 03 | 404.11 | 394.29 | +2.49% |
| 11 | 390.52 | 401.63 | −2.77% |
| 17 | 361.88 | 369.06 | −1.95% |
| 19 | 395.22 | 398.45 | −0.81% |

[40회 개별 측정](evidence/fragmentation/benchmark/timings.csv)의 분산이 커 빨라졌다고 일반화하지 않는다.
예를 들어 19번은 기존 265.0–440.8, 후보 306.3–414.9 FPS다.

실제 앱이 lossless 합성 영상을 읽는 테스트에서 신체 조각 3개를 두 사람·기존 두 ID로 유지했다.
얇은 목, 가까운 사람, 모호한 소유권, 만료된 기준 객체, 신규 조각, 1×/2×/4× 비율, 평가 오인과 SIFT도 검증했다.
당시 테스트는 **148 통과·1 제외**(Linux에 macOS CA 번들 없음), Ruff·diff 검사 통과였다. 실제 영상 일반화의 대체 증거는 아니다.
변경 전 앱과 재구성을 끈 새 앱의 17개 전체 활성 ID·bbox trace가 일치했고, 후보의 전경 단계 진단·조각 수도 동일했다.

기존 추적 평가는 IoU ≥0.1 일대일 대응, ID 5프레임 확정, 미대응 10프레임 이상 연속 구간당 실패 1회로 정의했다.

작은 신체 조각도 정상 대응이 될 수 있으므로 이번 전신 포착 검증을 대신하지 못한다.
학습률 픽셀 GT 원본은 이번 세션에 없어 재실행하지 않았다. ROI 매칭은 기하 검증·오검출 평가를 하지 않아 전체 프레임 인식률이 아니다.

면적 임계값 상승·무조건 bbox 병합·신규 ID 일괄 지연은 검출을 숨기거나 다른 사람을 합칠 수 있어 해결책으로 채택하지 않았다.
그림자 전체 복원·전역 커널 확대도 사람별 소속 단서를 추가하지 못한다. 이 대안 모두를 실험한 것은 아니다.

## 구조적 한계와 다음 단계

사라진 전경에는 합칠 조각이 없고, 붙어 있는 사람에게는 중심점 외 정체성 단서가 없다.
이번 조합의 한계는 측정했지만 모든 고전적 방법이 불가능하다고 입증한 것은 아니다.
다음은 도입 제안이며, 이 저장소에서 효과·속도를 측정한 결과는 아니다.

| 대안 | 기대 효과 | 도입 비용·남은 위험 |
| --- | --- | --- |
| 사람 검출 + 전경 보조 | 정지·신체 연결 여부와 독립적인 사람 단위 관측 | 가중치·배포 조건, 추론 환경, 전처리·좌표 복원·중복 제거, CPU/GPU 지연과 작은 사람 검증 |
| 사람 인스턴스 분할 | 붙은 전경의 사람별 픽셀 소속 추정 | mask 처리·메모리·픽셀 GT 비용, 완전 가림 보장 없음 |
| 운동 예측 + 외형 대응 | 교차·재등장 ID 안정화 | 특징 추출·전역 대응·트랙 생명주기, 같은 옷·장기 가림 실패; 검출 결손 자체는 해결 못함 |

앱 전체를 다시 만들 필요는 없다. 객체 관측·대응을 교체하고 SIFT·입출력·평가 체계는 유지할 수 있다.
새 방식을 개발하면 이번 검증 세트를 재튜닝에 쓰지 말고 **새 영상 단위 최종 검증 세트**를 확보해야 한다.
