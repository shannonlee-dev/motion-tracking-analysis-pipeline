> 현재 평가 범위: CAVIAR `walking`·`meeting`·`stopping` 3개, LASIESTA 조명 2개와
> 가림·정지 3개, 합성 추적 30시험·파라미터 비교, ALOI 물체 1개의 특징점 매칭.
> 실제 영상 평가 결과는 `results/current/`에 저장한다. 아래 CAVIAR 표도 이 3개 영상만 다룬다.

## 미션 필수 평가표

ALOI 전수평가는 수행 범위에서 제외했다. 동일한 target 1개에 대한 필수 5조건,
기존 추적 30회와 learning-rate 3종 비교를 중심으로 정리한다.

매칭률 = 매칭 수 / 등록 이미지 특징점 수 × 100이다. 장면 특징점 수를 분모로 쓰지 않는다.
정면은 등록 이미지의 자기 매칭이며, r30/r60은 실제 촬영 시점 변화다.
ORB는 앱의 기하 검증까지 실행한다. SIFT는 대응점·인라이어를 비교하는 참고 방법이며 앱 인식을 채점하지 않는다.
모든 장면에 동일한 80픽셀 검은 여백을 추가했다. 등록 이미지 해상도를 바꾸지 않았다.

가림은 동일 target의 정면 마스크 전경 **113,523픽셀**을 기준으로 왼쪽부터 회색 커튼을 씌웠다.
30% 가림은 **34,057픽셀(30.000088%)**, 50% 가림은 **56,762픽셀(50.000440%)**이다.
원하는 비율에 가장 가까운 정수 픽셀 수를 사용했다. 사진 전체 면적이나 bbox 면적 기준이 아니다.
가림 조건은 실제 물체 사진에 만든 통제 변형이고, 정면·회전 조건은 원본 사진이다.

ORB는 30°/60°에서 인식에 실패했지만 30%/50% 가림에서는 인식을 유지했다.
따라서 회전·가림이 항상 실패를 일으킨다고 결론 내리지 않는다. 물체 1개의 조건 비교이며 일반적인 성공률은 아니다.

## 통제 실험과 추적 분석

### 1. 결과와 범위

OpenCV MOG2·윤곽선 검출·거리 기반 Tracker·ORB 재인식을 구현했다.
웹캠/파일 입력, ID·박스·중심점·궤적·FPS 표시, q/p/s 제어, MP4/CSV 저장을 지원한다.
딥러닝 탐지기, dnn, MediaPipe는 사용하지 않았다.

CAVIAR 실제 영상 3개(`walking`·`meeting`·`stopping`)와 통제 실험 30개를 평가했다. 핵심 결과는 **단일 이동보다 겹침·정지·조명 변화에서 실패가 증가한다**는 것이다.
아래 숫자는 직접 실행한 자동 측정값이다. 실제 촬영 30회나 사람의 수동 전수계수로 표현하지 않는다.
대표 캡처의 육안 점검은 수행했지만, 미션이 요구한 조건별 수동 전수계수를 완전히 대체하지 않는다.
30개 시험의 전체 연결 구간을 읽고 표본 캡처를 대조한 AI 검토 결과는 `docs/review.csv`에 분리했다.
이 기록은 자동 연결에 의존하며 사람의 독립적인 수동 전수계수가 아니다. 방법과 한계는 아래 검증과 수동 검토 절에 있다. 같은 CSV에 검토자를 구분해 기록한다.

### 2. 입력 자료와 실행 환경

원본: [CAVIAR 공식 자료](https://homepages.inf.ed.ac.uk/rbf/CAVIARDATA1/).
출처: EC Funded CAVIAR project/IST 2001 37540. 공식 페이지의 BY-SA 조건을 따른다.
로컬 파일명과 원본 시나리오 대응·이용 조건은 `data/NOTICE.md`, 파일 해시는 `data/sources.json`에 있다.
필수 20~30초 겹침 영상으로 **Meet_WalkSplit (`meeting.mpg`, 24.96초)**를 사용했다.

실험 환경: Python 3.12.3, OpenCV 4.13.0, NumPy 2.4.3, CPU 처리, OpenCV 스레드 1개, seed 42.
기본값: learning_rate=0.01, min_area=80px², kernel=3, max_distance=50px, max_missing=15, warmup=25프레임.

통제 실험은 각각 320×240, 25 FPS, 625프레임(25초)이다.
처음 50프레임은 물체가 없고, 물체가 있는 평가 구간은 f50~574다.
단일 이동·겹침 각 10회, 정지·조명 변화 각 5회이며 총 30회다.
시험마다 물체 폭·수직 위치·이동 경로를 정해진 규칙으로 바꾼다.
같은 환경의 제한된 변형이며 독립적인 현장 표본이 아니므로 모집단 성능이나 신뢰구간으로 일반화하지 않는다.
측정은 생성된 원래 프레임 배열에서 수행한다. MP4는 관찰용 인코딩 사본이므로 이를 다시 디코딩한 앱 결과에는 압축에 따른 차이가 날 수 있다.

### 3. 측정 기준

- **정답 연결:** 실제 검출된 박스와 정답 박스를 IoU ≥ 0.1로 일대일 최대 겹침 순서로 연결한다. 낮은 임계값은 배경 차분으로 사람의 일부만 검출되는 경우를 허용하기 위한 선택이며 결과에 영향을 준다.
- **전체 ID 변경 (`id_switches`, 기존 참고값):** 최초 ID가 5프레임 연속 유지되어 기준이 된 뒤 다른 ID가 5프레임 연속 유지되면 1회. 중간 미검출은 새 ID의 연속성을 끊는다. 기존 ID가 사라진 후 새 번호를 받는 단절도 포함한다. 다른 실제 물체와의 엄밀한 ID 교환만을 뜻하지 않는다.
- **겹침 이후 ID Switch (`post_overlap_switches`):** 겹침 직전 마지막으로 5프레임 이상 확정된 ID를 기준으로, 완전히 분리된 다음 프레임부터 다른 ID가 5프레임 연속 유지되면 센다. 겹침 전·도중의 변경 자체는 세지 않는다. 분리 후 연속 확인을 새로 시작하며, 이후 다시 다른 ID가 5프레임 유지되면 추가로 센다. 기준 ID가 없으면 처음 확정되는 ID를 변경으로 세지 않는다.
- **추적 실패:** 대상이 존재하는 평가 가능 프레임에서 미검출/ID 미부여가 10프레임 연속이면 1회. 20프레임 연속 누락도 하나의 실패 구간이다. 재검출 후 다시 10프레임 누락되면 추가 1회다.
- **가림:** 합성 영상은 뒤에 그린 물체가 앞 물체에 가려진 정확한 면적 비율을 안다. 50% 이상 가려진 물체는 연결 후보와 실패 분모에서 제외한다. 제외 프레임은 연속 실패/변경 후보를 끊지만 마지막 확정 ID는 보존한다.
- **실패율:** 실패 구간이 하나 이상 발생한 시험 수 / 시험 수. 별도의 미검출 프레임률은 미검출 객체-프레임 / 평가 가능 객체-프레임이다.
- **단위:** 두 물체 시험의 ID 변경·실패 구간은 두 물체의 합계이므로 시험 수보다 클 수 있다. 초기 학습 구간은 평가하지 않는다. 보존 중인 stale track은 실제 검출로 세지 않는다.

미션 기준의 겹침 이후 계수와 기존 전체 ID 변경을 별도 열로 구분한다.
합성 시험의 `overlap_start`·`overlap_end`는 두 정답 사각형의 교집합 면적이 0보다 큰 전체 구간이다.
뒤 물체의 50% 이상 가림 제외 구간과는 다르다. 각 시험은 겹침 이벤트 하나이며,
실제 영상의 겹침·가림 구간을 이 규칙으로 자동 확정하지 않는다.
겹침 없는 조건의 `post_overlap_switches`는 해당 없음(빈 CSV 값)이며, 측정된 0회가 아니다.
두 지표 모두 자동 정답 연결에 의존한다. 미션의 사람 수동 관찰은 아래 기록 절차로 별도 완료해야 한다.
프레임은 0 기반, 범위는 양끝을 포함한다.
`results/tracking_trials.csv`에 영상명·조건·프레임 범위·ID 변경·실패·관찰 메모가 모두 있다.
`synthetic_objects.csv`에는 물체별 결과, `traces/`에는 프레임별 정답-ID 연결과 가림 제외가 있다.

### 5. 배경 모델의 학습률

MOG2는 픽셀마다 여러 가우시안으로 배경을 모델링하고, 관찰값이 배경 분포에 맞지 않으면 전경으로 분리한다.
단순 이동 평균의 `새 배경 ≈ (1−α)×기존 배경 + α×현재값`은 학습률의 직관이며 MOG2 전체 수식은 아니다.
명시적인 학습률을 `apply`에 전달했다. [OpenCV MOG2 문서](https://docs.opencv.org/4.13.0/javadoc/org/opencv/video/BackgroundSubtractorMOG2.html)

아래는 f300~399에서 전체 이미지 중 전경 마스크 비율의 평균이다(커널 3).
정지 시 물체 보존 정도와 조명 급변 시 화면 전체 오검출을 구분하기 위한 보조 지표이며 추적 성공률 자체는 아니다.

| 학습률 | 정지: 전경 비율 | 조명 변화: 전경 비율 |
| --- | --- | --- |
| 0.001 | 0.31% | 97.59% |
| 0.01 | 0.07% | 10.36% |
| 0.1 | 0.00% | 0.00% |

낮은 0.001은 정지 물체를 더 오래 전경으로 유지하지만 조명이 바뀐 배경 적응이 늦다.
높은 0.1은 조명 변화에 빨리 적응하는 대신 천천히 움직이거나 정지한 물체를 더 빨리 배경에 흡수한다.
학습률을 낮추는 선택 하나로 두 문제를 동시에 해결할 수 없다.
조명 변화 직후 전체 화면에 가까운 마스크가 나타나면 최대 면적 필터가 이를 제거하므로,
대형 오검출이 줄어도 실제 물체의 추적이 실패할 수 있다.

![느린 적응, 조명 변화 직후](../results/captures/mask_lighting_0.001_310.jpg)

![빠른 적응, 조명 변화 직후](../results/captures/mask_lighting_0.1_310.jpg)

그림자 라벨 127은 제거하고 전경 255만 남긴다. 그림자를 없애는 데 도움이 되지만 어두운 실제 물체 일부도 손실될 수 있다.
배경에 처음부터 있던 사람은 학습 시 배경의 일부가 된다. 초기 warmup을 늘리는 것만으로 정지 사람 검출을 해결하지 못한다.

### 6. 모폴로지와 규칙 추가 실험

열림은 작은 점 노이즈를 지우고 닫힘은 작은 구멍·틈을 메운다.
타원형 커널 1·3·7을 비교했다. 1은 사실상 무처리, 7은 좁은 전경 조각을 지우거나 가까운 영역을 합칠 수 있다.
이번 통제 배경에는 센서 잡음이 거의 없어 커널의 노이즈 제거 이득보다 작은 물체 형상 손실이 크게 나타날 수 있다.

| 설정 | 겹침 ID 변경 | 겹침 실패 구간 | 정지 실패 구간 | 조명 실패 구간 |
| --- | --- | --- | --- | --- |
| baseline | 27 | 7 | 5 | 10 |
| lr_0.001 | 20 | 20 | 5 | 5 |
| lr_0.1 | 0 | 30 | 5 | 5 |
| kernel_1 | 20 | 13 | 5 | 10 |
| kernel_7 | 0 | 40 | 8 | 5 |
| distance_20 | 27 | 7 | 5 | 10 |
| distance_80 | 27 | 7 | 5 | 10 |
| velocity | 41 | 7 | 5 | 10 |

각 설정은 나머지 값을 고정하고 같은 30개 시험을 처음부터 다시 실행했다.
`lr_0.001`/`lr_0.1`은 학습률, `kernel_1`/`kernel_7`은 커널 크기,
`distance_20`/`distance_80`은 연결 거리, `velocity`는 마지막 이동 속도에 의한 위치 예측이다.
모든 조건의 상세 수치는 `tracking_summary.csv`와 `background.csv`에 있다.
학습률 0.1의 ID 변경 0회는 성공이 아니다. 해당 설정은 평가 가능한 객체-프레임을 100% 놓쳐 안정된 ID 자체가 형성되지 않았다.
커널 7 역시 겹침 미검출률이 97.51%이므로 ID 변경 0회를 개선으로 보면 안 된다.
거리 20/50/80에서는 겹침 결과가 동일했고, 속도 예측은 오히려 ID 변경을 27회에서 41회로 늘렸다.

거리 제한을 줄이면 먼 잘못된 연결을 차단하지만 재등장·빠른 이동을 새 ID로 만들기 쉽다.
제한을 늘리면 오래된 ID에 연결하기 쉬워지고, 속도 예측도 겹침 중 잘못 연결한 중심점이나 갑작스러운 방향 전환에 영향을 받는다.
표에서 특정 규칙이 개선되더라도 위치 정보가 사라진 순간에 외형을 복원한 것은 아니다.
**위치만으로 두 객체를 구분할 수 없는 경우가 존재한다.**

### 7. 특징점 매칭 성능

직접 생성한 180×180 평면 패턴을 등록하고, 320×320 장면에 삽입했다.
ORB 1,500개 상한, Hamming kNN, Lowe ratio 0.75, 장면 특징점 중복 제거,
RANSAC 재투영 오차 3px·인라이어 최소 8·인라이어 비율 50% 이상으로 판정한다.
또한 사각형의 유한 좌표·볼록성·면적을 검사한다. 매칭 수만 많다고 발견으로 판정하지 않는다.
조건마다 삽입 위치를 조금 바꾼 10개 장면을 사용했다.

| 조건 | 등록 특징점 | 장면 특징점 평균 | 매칭 평균 | 인라이어 평균 | 매칭률 | 인식 성공 |
| --- | --- | --- | --- | --- | --- | --- |
| 정면 | 648 | 1434.4 | 344.2 | 341.1 | 53.12% | 10/10 |
| 평면 내 30° 회전 | 648 | 1440.7 | 224.4 | 216.9 | 34.63% | 10/10 |
| 평면 내 60° 회전 | 648 | 1435.7 | 222.3 | 218.9 | 34.31% | 10/10 |
| 30% 가림 | 648 | 1368.6 | 311.8 | 310.0 | 48.12% | 10/10 |
| 50% 가림 | 648 | 1159.4 | 163.4 | 162.1 | 25.22% | 10/10 |

매칭률 분모는 등록 이미지 특징점 수이며, 매칭 수는 ratio test와 일대일 정리를 통과한 대응점 수다.
특징점 수와 매칭률은 성공률과 다르다. 매칭 수가 줄어도 남은 8개 이상의 기하학적으로 일관된 특징으로 인식에 성공할 수 있다.
가림은 패턴의 왼쪽 30% 또는 50% 면적을 배경색으로 덮는 방식이다.
30°·60°는 **영상 평면 안의 회전**이며 카메라에 대한 3차원 기울기 실험이 아니다.
등록 패턴 한 개의 변환이므로 임의의 실물에 대한 인식률로 일반화하지 않는다.

![조건별 ORB 재인식](../results/captures/features.jpg)

ORB와 SIFT는 회전 불변성을 의도한 방법이다. 따라서 “회전하면 반드시 실패한다”는 결론은 부정확하다.
ORB는 방향을 추정해 BRIEF 샘플링을 회전시킨다.
회전 후 보간·검출 위치 변화·방향 추정 오차로 대응점이 줄 수 있고, 가림은 사용할 특징 자체를 없앤다.
원근 변화·흐림·반사·비평면 변형·반복 무늬는 추가적인 실패 요인이다.
[OpenCV ORB 설명](https://docs.opencv.org/4.13.0/d1/d89/tutorial_py_orb.html)

“학습되지 않은 특징”이라는 표현도 구분이 필요하다.
ORB의 rBRIEF에는 통계적 특성으로 비교쌍을 선택하는 과정이 있지만,
현재 앱은 물체 정체성이나 작업 환경에 맞게 외형 임베딩을 학습하지 않는다.
고정된 국소 비교 규칙은 새로운 재질·시점·촬영 환경에서 안정적인 정체성을 보장하지 못한다.
이 합성 패턴 표는 ORB만 측정했다. SIFT는 `scripts/eval/aloi.py`의 별도 ALOI 비교 실험에서
초기화·특징점 검출·L2 kNN 매칭·RANSAC 인라이어 측정을 수행하며,
결과는 `results/aloi_features.csv`의 `SIFT_reference` 행에 저장한다. 앱의 표적 인식은 ORB다.

실제 파일로 재생한 표적 데모는 625프레임 중 525프레임에서 발견되었다.
표적은 f50~574에만 존재하며, 이 전체 프레임 대비 수치는 정확도가 아니다.
평균 처리 속도(저장 포함)는 73.1 FPS였다.
음성 장면의 일반적인 오탐률은 별도 자연영상 집합으로 측정하지 않았다.

### 8. CCTV 운영 대응과 딥러닝 개선 방향

| 조건 | 현재 실패 원인 | 운영 대응 |
| --- | --- | --- |
| 낮은 시점·밀집 통로 | 사람끼리 윤곽선 합침·장시간 가림 | 카메라 높이·시야 조정, 서로 보완하는 시점 확보 |
| 원거리·작은 사람 | 면적 필터·모폴로지로 소실 | 관심 영역별 크기 조정, 충분한 해상도 확보 |
| 자동 노출·역광·조명 켜짐 | 배경 전체가 전경으로 변함 | 노출/화이트밸런스 안정화, 조명 변화 구간 구분 |
| 카메라 흔들림 | 모든 배경이 움직임으로 검출 | 고정 마운트, 영상 안정화 후 검출 |
| 정지·재등장 | 배경 흡수·ID 수명 만료 | 정지 물체 검출과 재식별을 별도 설계 |

**외형을 학습하면 겹침 문제가 해결될까?**
이번 겹침 실험에서 위치와 중심점만으로 잃어버린 정체성을 구분하지 못했다.
보행자 탐지와 Re-ID 임베딩을 결합하면 분리 후 이전 외형과 비교할 수 있어 도움이 된다.
하지만 완전 가림·동일한 옷·매우 낮은 해상도에서는 여전히 모호하다. 해결을 보장하지 않는다.
같은 사람의 여러 시점·가림 전후 이미지, 구분하기 어려운 다른 사람 쌍, 연속 ID 라벨이 필요하다.

**다양한 변형을 학습하면 매칭이 개선될까?**
학습된 특징과 회전·원근·흐림·가림 증강은 대응점을 더 안정적으로 만들 가능성이 있다.
현재 평면 패턴을 넘어 실제 재질과 촬영 시점, 비평면 변형이 포함된 데이터가 필요하다.
학습에 사용하지 않은 물체와 장소로 시험 세트를 분리해 일반화를 확인해야 한다.

**환경 변화를 학습하면 배경 모델링이 강건해질까?**
밝기 변화 자체에 반응하는 배경 차분 대신 객체 의미를 학습한 탐지·분할은 조명 변화 중에도 대상을 찾는 데 도움이 된다.
주야간·역광·그림자·카메라별 노출·빈 장면·정지 대상의 데이터와 라벨이 필요하다.
도메인이 바뀌면 성능이 하락할 수 있으므로 현장별 검증과 시간에 따른 데이터 분리를 유지해야 한다.
이번 프로젝트는 이러한 딥러닝 개선안을 구현하거나 성능 향상을 측정하지 않았다.

### LASIESTA: 실제 조명 변화와 MOG2

I_IL_01은 전등 켜기, I_IL_02는 블라인드 열기와 퇴장 장면이다.
두 번째 장면에는 조명뿐 아니라 영구적인 배경 변화도 있으므로 순수한 느린 조명 변화로 단정하지 않는다.
352×288 원본 300/525프레임을 순서대로 사용했다. 출처에서 원본 FPS를 확인하지 못해 초 단위 길이는 주장하지 않는다.
학습률 0.001/0.01/0.1만 바꾸고 각 실행마다 MOG2를 초기화했다. 첫 25프레임은 평가에서 제외했다.
MOG2 shadow=127은 제거하고 앱과 동일한 3×3 열림·닫힘 이후의 전경 마스크를 평가한다.
공식 GT의 빨강·초록·노랑과 정지 물체의 흰색을 전경으로, 검정을 배경으로 사용했다.
불확실한 회색(128)은 분모에서도 제외했다. 여기의 F1은 픽셀 분할 성능이며 ID 유지율이 아니다.

| I_IL_01 | 0.1 | 0.8388 | 0.0004 | 0.0009 | 0.0000 | 0 |
| I_IL_02 | 0.001 | 0.1447 | 0.8627 | 0.2478 | 0.1397 | 156 |

| I_IL_02 | 0.1 | 0.7294 | 0.0005 | 0.0011 | 0.0000 | 0 |

Precision=TP/(TP+FP), Recall=TP/(TP+FN), F1=2TP/(2TP+FP+FN), 배경 오검출률=FP/(FP+TN)이다.
영상 전체의 픽셀 혼동행렬을 먼저 더해 계산했다. 원본 f26 이후 인접 프레임의 평균 회색 밝기 차이가
가장 큰 프레임은 I_IL_01 f129, I_IL_02 f216이다. 회복 지연은 그 프레임부터
배경 오검출률 ≤1%가 연속 10프레임 유지되기 시작할 때까지의 프레임 수다.
이는 프로젝트가 정한 보조 지표이며, 블라인드 변화 전체를 한 순간으로 정의한 것이 아니다.

학습률 0.001은 사람이 잘 남지만 조명 변화로 배경이 오래 전경이 된다.
0.01은 이 두 영상에서 F1이 가장 높았다. 0.1은 배경 오검출을 빠르게 줄였지만
사람 전경의 Recall도 거의 0이 되었다. **배경이 빨리 안정된다는 것만으로 추적이 좋아졌다고 볼 수 없다.**
이 두 장면의 결과를 다른 카메라에서의 최적 학습률로 일반화하지 않는다.

### ALOI: 실제 시점·조명·면적 기준 가림

필수 5조건과 같은 물체·등록 이미지로 조명 방향 및 색온도를 추가 비교했다.
비평면 물체에 호모그래피를 적용하는 모델 한계, 마스크 경계 오차와 한 방향 가림의 한계가 있다.

| l1c1 | ORB_app | 907/1448 | 11 | 4 | 1.21% | 0 |
| l1c1 | SIFT_reference | 127/260 | 3 | 0 | 2.36% | 해당 없음 |

매칭률의 분모는 등록 이미지 특징점 수다. 장면 특징점 수로 나눈 값이 아니다.
두 방법 모두 ratio 0.75, 장면 특징점 중복 제거, RANSAC 3픽셀을 적용했다.
ORB는 실제 앱의 기하 검증까지 실행했다. SIFT는 대응점·인라이어만 비교하므로 앱 인식 여부는 비워 두었다.
ORB 정면은 성공하고 r30/r60은 실패했다. r30은 인라이어가 11개 있어도 앱의 모든 기하 조건을 통과하지 못했다.
30%·50% 가림은 매칭 수가 감소했지만 인식을 유지했다. 가림이 있다고 반드시 실패한다고 해석하지 않는다.
방향 조명 l1c1에서 실패한 반면 l8c1·색온도 i110/i250에서는 성공했다.
물체 하나·조건별 한 이미지의 결과이므로 성공률의 신뢰구간이나 보편적인 SIFT 우위는 주장하지 않는다.
로컬 확인 그림은 `data/aloi/raw/evaluation.jpg`에 재생성한다.

### 검토 방법과 남은 작업

2026-09-11 Codex(AI)가 30개 통제 시험의 전체 정답-ID 연결 구간
`results/visual-review/runs.csv`를 읽고 대표 프레임 시트를 대조했다.
5프레임 ID 변경·10프레임 미검출 기준으로 계수한 기록은 [review.csv](review.csv)에 있다.
요약 CSV 집계값을 복사한 기록은 아니지만, GT 연결 자체가 자동 IoU 기반이므로
독립적인 정답 검증이나 사람의 수동 전수계수로 해석하지 않는다.
ID 변경은 두 객체 간 교환 외에 재등장 시 번호 단절도 포함한다.

| 조건 | AI 검토 결과 |
| --- | --- |
| 단일 이동 10회 | 대상 ID 1 유지. 02/05/08번의 추가 박스는 중복 검출 |
| 겹침 10회 | ID 변경 27회, 실패 구간 7회, 실패 시험 7/10. 9프레임 누락은 제외 |
| 정지 5회 | ID 변경 5회, 실패 구간 5회, 실패 시험 5/5. f235~385 누락은 각 1구간 |
| 조명 5회 | ID 변경 3회, 실패 구간 10회, 실패 시험 5/5. f300~309는 실패에 포함 |

기존 30개 시트와 전체 연결 구간은 검토 근거로 보관한다.
시트는 실험과 같은 원래 프레임 배열을 사용한다. 모든 원본 프레임을 육안으로 확인한 것은 아니다.

사람의 수동 측정은 미완료다. `docs/review.csv`에는 기존 AI 기록 30행과
사람이 작성할 합성 30시험·실제 영상 3개 보조 검토 행을 구분해 두었다.
기존 AI 행의 `metric_scope=all_confirmed_id_changes`는 전체 ID 변경 참고값이다.
`review_status=needs_human_review` 행의 계수·검토자는 비워 두었으며 자동 계수를 복사하지 않는다.

1. `python -m scripts.eval.run --export-videos`로 관찰 영상을 준비한다. `data/clips/`는 합성 입력,
   `results/videos/`는 같은 실행의 합성 ID·프레임 번호 표시 영상이다. CAVIAR 3개는 `results/current/videos/caviar_*.mp4`다.
2. 각 행의 `evidence` 영상을 프레임 이동이 가능한 플레이어로 확인한다. 합성은 전체 25초 중
   f50~574를 관찰한다. 사각형 내부의 1/2는 실제 객체 번호이고 `ID:`는 추적 번호다.
   앱으로 다시 분석하면 압축 영향으로 다른 ID가 나올 수 있으므로 저장된 오버레이를 먼저 본다.
3. 겹침 시험은 `overlap_start` 직전 확정 ID와 `overlap_end` 이후 5연속 프레임을 비교해
   `id_switches`에 수동 계수를 쓴다. 겹침 없는 합성 조건은 `metric_scope=no_overlap`이며
   `id_switches`에 `해당 없음`을 쓴다. 예상하지 못한 전체 ID 변경은 관찰 메모에 따로 기록한다.
4. 대상이 존재하는데 검출 박스·ID가 10연속 프레임 없는 구간마다 `failures`를 1회씩 센다.
   50% 이상 가림은 제외하고 `occlusion`에 객체 번호·프레임 범위를 기록한다.
   사건별 구간·변경 전후 ID를 `observation`에 적고 실제 검토자와 `human_reviewed` 상태를 기록한다.
5. 합성 조건별 완료 행이 10/10/5/5인지 확인한 뒤 수동 실패율을 실패가 있는 행 수 / 해당 조건 행 수로 계산한다.
   실제 영상 3행은 보조 기록이며 합성 30시험에 합산하지 않는다. 실제 영상은 대상별 겹침·가림 구간과
   XML 정렬을 별도로 확인해야 하며, 박스 교집합 비율을 실제 신체 가림 비율로 대신하지 않는다.

완료된 수동 계수는 이 보고서에 별도로 반영한다. 자동 계수와 차이가 나면 연결 오류·가림 제외·5/10프레임 경계를 대조한다.
실제 CAVIAR 영상의 프레임 정렬과 가림 비율, 실물 웹캠·물리적 데스크톱 검증은 남아 있다.

이 보고서와 검토 시트는 실험 재실행으로 자동 갱신되지 않는다.
측정값이나 수동 검토 결과가 달라지면 해당 표와 근거를 함께 갱신한다.
